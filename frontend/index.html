Measured working area

Use this method to save your working-area dimensions and marker positions.

Enter measured marker-centre positions in millimetres. For a rectangle, enter its width and height and apply them to the rows below. For other four-corner layouts, edit each X/Y coordinate directly. All four markers must be flat on the material plane and visible in the captured photo.

Shared marker frame: ID 12 = (0, 0), ID 11 = (-width, 0), ID 13 = (0, -height), and the opposite marker = (-width, -height). -X points toward ID 11; -Y points toward ID 13. Width and height are measured centre-to-centre distances. Save marker positions to persist the rows without a camera. Editing width/height and saving also fills the rectangular rows automatically. Photo calibration still requires all four markers.

      DXF -> laser coordinates

      Camera measurements and nesting use ID 12 centre (0, 0), with -X toward ID 11 and -Y toward ID 13. DXF export translates the top-right corner of the box around all nested templates to (0, 0), without changing size, rotation or spacing. The yellow box and origin marker are preview guides only; they are not exported as cutting paths. Set the physical laser job origin separately.

      Subtract the design reference, reverse chosen axes, rotate, then add the laser reference. Dimensions stay in mm. Positive rotation goes from +X toward +Y. Bounds references use the full layout including the sheath. The automatic template reference uses the top endpoint of the rightmost cut edge and is recalculated for every DXF.

      Match your laser software's origin mode and import at 1:1 without automatic centering. For a head-set job origin, use laser X/Y = 0. For fixed bed coordinates, enter the measured reference position. Preview uses +Y upward. SVG uses the original design coordinates.
